# ShopSphere - Django E-Commerce Website

A full-stack e-commerce website built using Python, Django, MySQL, HTML, CSS and JavaScript.

## Technologies

- Python
- Django
- MySQL
- HTML
- CSS
- JavaScript

## Features

- User Registration and Login
- Product Listing
- Product Search
- Product Categories
- Shopping Cart
- Checkout
- Order Management
- Admin Dashboard
